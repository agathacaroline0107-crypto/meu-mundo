## Calculadora de Holerite (app)

Pasta `holerite/`: aplicativo instalável (PWA) que calcula o salário líquido a partir do ponto em PDF e confere o holerite.
Endereço: https://agathacaroline0107-crypto.github.io/meu-mundo/holerite/
Os PDFs e as consultas ficam só no aparelho de quem usa; nada é enviado para o servidor.
